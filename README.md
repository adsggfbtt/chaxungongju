# PHP 分流跳转系统

该项目提供一个简单的 PHP 网址分流系统，用于广告投流或链接轮询跳转。访问主入口 `index.php` 时，会按顺序轮流跳转到后台配置的目标链接，并记录点击统计。

## 功能

- 轮询分流（Round-robin）跳转
- 点击统计（总点击 + 每个链接点击次数）
- 后台配置分流链接

## 快速开始

1. 部署到支持 PHP 的服务器。
2. 修改 `config.php` 中的 `admin_password`。
3. 打开 `/admin.php` 登录管理后台，配置分流链接。
4. 将广告投放链接设置为 `index.php` 的访问地址。

## 文件说明

- `index.php`: 主入口，处理轮询跳转与统计。
- `admin.php`: 后台管理界面，配置分流链接并查看统计。
- `data/links.json`: 分流链接存储。
- `data/state.json`: 轮询状态。
- `data/stats.json`: 点击统计。

## 注意事项

- 请确保 `data/` 目录可写。
- 建议为 `admin.php` 设置更安全的访问方式（如 IP 白名单、独立登录系统等）。
