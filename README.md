# PHP 网址分流系统

该项目提供一个轻量级的 PHP 分流入口与后台配置页面，支持轮流跳转与点击统计，适合广告投放场景。

## 运行方式

```bash
php -S 0.0.0.0:8000
```

- 入口地址：`http://localhost:8000/index.php`
- 后台管理：`http://localhost:8000/admin.php`

## 使用说明

1. 进入后台管理页面，填写分流链接（每行一个）。
2. 保存后访问入口地址，将按顺序轮流跳转。
3. 后台页面会展示每个链接的点击统计与总点击数。

## 数据文件

- `data/config.json`：保存分流链接与轮询索引。
- `data/stats.json`：保存点击统计。
